# Personal Portfolio

A modern, minimal personal portfolio built with React + Vite and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this project to GitHub.
2. Import the repository in Vercel.
3. Use the default build settings.
4. Deploy.

## Edit content

- Replace the name, bio, links, and project details in the relevant files under src/components and src/data.
- Update colors in src/index.css.
